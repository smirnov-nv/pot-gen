# Генератор рассадных горшков

Параметрический конструктор квадратных горшков под печать в режиме вазы
(spiral vase) на FDM-принтере. Крутите параметры — модель пересобирается в
3D в реальном времени, рядом считаются объём субстрата, граммы филамента,
время печати и шаг вложения, а непечатаемые сочетания подсвечиваются с
объяснением, чем именно они плохи. На выходе — binary STL.

Приложение локальное: без бэкенда, без аккаунтов, без сети. Вся геометрия
считается в браузере, тяжёлая часть — в Web Worker.

```
┌──────────────┬────────────────────────────┬──────────────────┐
│  Форма       │                            │  Метрики         │
│  Гофр        │                            │  0.47 л, 31 г    │
│  Кромка      │        3D / 2D             │                  │
│  Сетка       │        превью              │  Предупреждения  │
│  Печать      │                            │                  │
│  Shell       │                            │  Настройки       │
│              │                            │  слайсера        │
└──────────────┴────────────────────────────┴──────────────────┘
```

## Быстрый старт

На хосте нужен **только Docker** — ни Node, ни pnpm, ни Python ставить не
надо, всё живёт в контейнерах (см. [docs/development.md](docs/development.md)).

```sh
git clone <repo> && cd pot_gen
make dev            # http://localhost:5173
```

Остальные команды:

```sh
make test           # тесты
make lint           # tsc --noEmit + eslint + docs:check
make build          # production-сборка в ./dist
make preview        # собранная статика через nginx на :8080
make fixtures       # перегенерировать golden-фикстуры из potgen.py
make shell          # shell внутри dev-контейнера
make help           # список целей
```

## Что это печатает

Квадратный горшок со скруглёнными углами, гофрированной стенкой и
развальцованной кромкой, сходящийся книзу — чтобы горшки вкладывались друг в
друга. Два режима генерации:

- **Режим вазы** — сплошное тело, слайсер обводит внешний контур одной
  непрерывной спиралью. Стенка в одну нитку, отсюда гофр: он и есть
  единственный источник жёсткости. Один горшок за печать.
- **Shell** — настоящая тонкостенная модель с дном, дренажными отверстиями и
  щелями для воздушной обрезки корней. Печатается как обычный объект, зато
  партией.

Подробно, с температурами и настройками Bambu Studio —
[docs/printing.md](docs/printing.md).

## Требования к среде

- Docker 24+ и Docker Compose v2. Больше ничего.
- Браузер с поддержкой WebGL2 и модульных Web Worker (Chrome 91+, Firefox
  114+, Safari 16.4+). Вёрстка десктопная, мобильной нет.

## Референс

`potgen.py` в корне — исходная реализация геометрии на Python, из которой
портирован TypeScript. Она остаётся источником истины: golden-тесты сравнивают
каждый треугольник STL с её выводом. Не удалять.

## [0.1.0] — 2026-07-27

Первый выпуск: параметрический генератор целиком, по спецификации `SPEC.md`.

### Добавлено

- **Окружение.** Multi-stage `Dockerfile` (base / deps / dev / build /
  runtime), отдельный `Dockerfile.python` для референса и фикстур,
  compose-сервисы `dev` / `test` / `lint` / `build` / `preview` / `fixtures`,
  `Makefile` как единственный интерфейс на хосте. На хосте нужен только
  Docker.
- **Ядро геометрии.** Порт `potgen.py` на TypeScript: суперэллипс, ресемплинг
  по длине дуги, гофр по нормали, конус, развальцовка кромки, кручение,
  триангуляция в замкнутый манифолд, binary STL.
- **Golden-тесты.** Фикстуры генерируются в питоновском контейнере и включают
  эталонный STL; сравнение идёт по каждой координате в пределах float32.
  Плюс манифольдность на 20 случайных наборах, ориентация нормалей, разброс
  ресемплинга, четырёхкратная симметрия, round-trip STL.
- **Метрики.** Полезный объём, масса и стоимость филамента, число слоёв,
  оценка времени, шаг вложения (измеряется опусканием копии до касания),
  угол стенки, период гофра.
- **Валидация.** Правила печатаемости из раздела 6 SPEC, каждое с объяснением
  причины; отдельный набор правил для shell-режима; постоянная памятка об
  ограничениях режима вазы.
- **UI.** Панель параметров, генерируемая из схемы; 3D-превью на three.js с
  орбитой, сеткой стола, каркасом и разрезом по XZ; 2D-виды (сечение сверху и
  профиль сбоку) с оверлеем дренажа; панели метрик, предупреждений и настроек
  слайсера с копированием в буфер.
- **Воркер.** Генерация меша и STL в Web Worker с transferable-буферами,
  дебаунсом и отбрасыванием устаревших ответов; прогресс-бар при экспорте.
- **Пресеты и шаринг.** Встроенные `P9 90×90×95` и `Small 78×78×82`,
  пользовательские пресеты в localStorage, импорт/экспорт JSON, параметры в
  URL hash, undo/redo с горячими клавишами.
- **Shell-режим.** Тонкостенная модель: внешняя и внутренняя поверхности,
  дно заданной толщины, настоящие дренажные отверстия, вертикальные щели для
  воздушной обрезки корней. Триангуляция многоугольника с отверстиями
  (мосты + отсечение ушей).
- **Документация.** `docs/geometry.md` с выводом всех формул и
  сгенерированными SVG-иллюстрациями, `docs/printing.md`,
  `docs/architecture.md` с Mermaid-схемой, `docs/api.md`,
  `docs/extending.md`, `docs/decisions.md`, `docs/development.md`. Таблица
  параметров в README генерируется из схемы, все примеры кода проверяются
  `pnpm docs:check`.

### Отклонения от SPEC

- Предел ширины экструзии — 2× диаметра сопла вместо 1.8×: указанные в SPEC
  дефолты 0.75 / 0.4 дают 1.875 и нарушали бы собственное правило. См.
  ADR-007.
- Период гофра измеряется по гладкому контуру кромки, а не по гофрированному.
  См. ADR-007.
- Байтовое совпадение STL с `potgen.py` заменено на совпадение каждой
  координаты в пределах float32: CPython и V8 расходятся на ulp в `cos`/`sin`.
  См. ADR-001.
